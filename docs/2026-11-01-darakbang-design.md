# 무화과 그룹 박준원 다락방 홈페이지 설계서

작성일: 2026-11-01

## 1. 목적

다락방 리더십이 공지·결단·일정·기도제목·간식 추천을 한곳에서 관리하고, 첫 화면에서 오늘 할 일(통독·암송·출석부·일정)을 바로 보는 모바일 웹페이지.

## 2. 전체 구조

- 배포: GitHub Pages, 저장소 `ukiahptc/27-haneul`, 경로 `/darakbang/`
- 데이터: 구글 시트 1개 (출석부와 별도 파일) + Apps Script 웹앱
- 사이트는 Apps Script 주소에서 JSON을 읽고, 같은 주소로 저장 요청을 보냄

```
darakbang/
├── index.html   화면 뼈대 (입장 화면 + 탭 6개)
├── style.css    무화과 테마
├── app.js       읽기/쓰기, 화면 그리기
└── config.js    Apps Script 주소, 출석부 링크
apps-script/
└── Code.gs      시트에 붙일 스크립트 (탭 자동 생성, 읽기/쓰기/인증)
```

### 데이터 흐름

- 입장: 비밀번호 → Apps Script 검증 → 토큰 발급 → 기기(localStorage)에 저장
- 읽기: 탭 진입 시 `?action=list&sheet=공지&token=...` 요청 → JSON 배열
- 쓰기: `POST {action:"save", sheet, row, token}` → 같은 id면 덮어쓰기, 없으면 추가
- 삭제: `POST {action:"delete", sheet, id, token}` → `삭제` 열에 Y 표시 (행 유지)
- 토큰 불일치 시 읽기도 빈 배열 반환
- 마지막 응답을 localStorage에 캐시해 먼저 그리고, 새 응답으로 갱신

## 3. 시트 탭 설계

모든 탭 첫 행은 제목 행, 첫 열은 `id`, 마지막 열은 `삭제`. Apps Script 최초 실행 시 자동 생성.

| 탭 | 열 |
|---|---|
| 공지 | id, 작성일시, 제목, 내용, 고정, 작성자, 삭제 |
| 결단 | id, 작성일시, 제목, 내용, 목표일, 상태, 작성자, 삭제 |
| 일정 | id, 날짜, 시작, 종료, 제목, 장소, 종류, 메모, 삭제 |
| 기도제목 | id, 작성일시, 이름, 내용, 응답, 응답메모, 삭제 |
| 간식 | id, 작성일시, 가게, 카테고리, 추천메뉴, 양, 맛, 속도, 한줄평, 추천인, 링크, 삭제 |
| 암송 | id, 시작일, 구절, 본문, 삭제 |
| 통독 | id, 날짜, 범위, 삭제 |

- 결단.상태: 진행 / 완료
- 일정.종류: 순모임 / 행사 / 기타
- 기도제목.이름: 선택 입력, 비우면 "익명" 표시
- 간식.양·맛·속도: 1~5 정수. 속도는 "별이 많을수록 순모임 진행에 방해가 적음"
- 간식.카테고리 기본 목록: 치킨 / 피자 / 중식 / 분식 / 한식 / 양식 / 카페·디저트 / 기타 (직접 입력 허용)
- 암송: 시작일 ≤ 오늘 중 가장 최근 행이 "이번 주 암송"
- 통독: 날짜 = 오늘 행이 대시보드에 표시. 사용자가 받은 통독표를 붙여넣음

## 4. 화면 구성

하단 고정 탭 바 6개. 모바일 우선.

### 입장 화면
무화과 로고, "무화과 그룹 박준원 다락방", 비밀번호 입력. 성공 시 토큰 저장 후 대시보드.

### ① 대시보드
| 영역 | 내용 | 비어 있을 때 |
|---|---|---|
| 오늘 통독 | 날짜 + 범위 | "오늘 통독 범위가 등록되지 않았어요" |
| 이번 주 암송 | 구절 주소 크게, 본문 아래 | "암송 구절이 등록되지 않았어요" |
| 출석부 | 버튼, 새 창으로 시트 열기 | 항상 표시 |
| 다가오는 일정 | 오늘~30일 이내 최대 5개. 날짜·요일·제목·장소. 당일 "오늘" 배지 | "예정된 일정이 없어요" |
| 진행 중 결단 | D-day 가까운 1~2개, "D-12" 형식 | 숨김 |

### ② 공지
고정 공지 상단, 나머지 최신순. 카드 탭하면 본문 펼침. 우하단 `+`로 작성. 카드 메뉴에서 수정·삭제.

### ③ 결단
진행 중 결단을 D-day 가까운 순. D-day 숫자를 카드 왼쪽에 크게. 지난/완료 결단은 접힘 구역. 완료 처리 버튼.

### ④ 캘린더
월간 달력, 이전/다음 달 이동. 일정 있는 날에 점 (순모임=자주, 행사=녹색, 기타=회색). 날짜 탭하면 아래에 그날 일정. `+` 작성 시 선택한 날짜가 기본값.

### ⑤ 기도제목
최신순 카드. 이름 비우면 "익명". "응답됨" 버튼 → 응답메모 입력 → 흐리게 표시, 접힘 구역으로 이동.

### ⑥ 순간식
상단 카테고리 칩(전체 + 목록). 카드: 가게, 추천메뉴, 별점 3줄(양·맛·속도), 한줄평, 추천인. 정렬: 최신순 / 맛순. 링크 있으면 "주문하러 가기" 버튼.

### 작성 폼 공통
하단에서 올라오는 시트. 저장 중 버튼 비활성. 실패 시 "저장 실패, 다시 시도" 표시하고 입력 유지.

## 5. 보안

- 비밀번호는 Apps Script 스크립트 속성 `PASSWORD`에 저장. 시트에 없음
- 토큰 = 비밀번호의 해시. 입장 시 1회 발급, 이후 모든 요청에 포함
- 토큰 불일치 시 읽기·쓰기 모두 거부
- 비밀번호 변경 = 스크립트 속성 수정. 모든 기기 재입장 필요
- 한계: 비밀번호 공유 수준의 보호. 기도제목 익명 입력 가능으로 보완

## 6. 무화과 테마

| 요소 | 값 |
|---|---|
| 바탕 | `#F6F1E7` 크림 |
| 글자 | `#2E2420` 진갈색 |
| 주색 | `#6B2D5C` 무화과 자주 |
| 보조색 | `#5B7A4E` 잎 녹색 |
| 포인트 | `#D98E9A` 속살 분홍 |
| 본문 글꼴 | Pretendard |
| 제목 글꼴 | Noto Serif KR |

- 카드: 가는 테두리 + 바탕색 차이. 그림자 없음
- 그라데이션·네온·이모지 사용 안 함
- 로고: 단순한 무화과 단면 SVG, 상단과 입장 화면에만
- 다크 모드 미지원 (크림색 고정)

## 7. 사용자 설정 절차 (구현 후 단계별 안내)

1. 구글 시트 새로 생성
2. 확장 프로그램 → Apps Script → `Code.gs` 붙여넣기 → 스크립트 속성에 `PASSWORD` 설정 → 웹앱으로 배포 (액세스: 모든 사용자) → 주소 복사
3. `config.js`에 Apps Script 주소와 출석부 시트 주소 입력 → push
4. 통독 탭에 통독표 붙여넣기
